# Veille technologique – Projet Front AgencEco

Ce document recense les axes de veille à suivre pour maintenir le projet front **AgencEco Website** à jour et pertinent.

---

## 1. Technologies utilisées
- **HTML5 / CSS3 / JavaScript**
- **Framework CSS** : Bootstrap / Tailwind (selon évolution du projet)
- **Librairies JS** : dépendances éventuelles (à surveiller)
- **Outils** : npm, Node.js, GitHub Pages ou autre hébergement statique

---

## 2. Axes de veille

### a) Performance et accessibilité
- Surveiller les bonnes pratiques **Lighthouse** (SEO, performance, accessibilité).
- Vérifier régulièrement les outils comme **PageSpeed Insights**.
- Suivre les recommandations **W3C**.

### b) Frameworks & librairies
- Évolution de **Bootstrap** et **TailwindCSS**.
- Nouvelles versions de **Node.js** et gestion des dépendances via **npm**.
- Alternatives plus légères ou adaptées (ex. Vite.js, Astro).

### c) Sécurité
- Mise à jour des dépendances (npm audit).
- Veille sur les vulnérabilités front (XSS, injections JS, dépendances compromises).

### d) UX / UI et tendances design
- Minimalisme, dark mode, micro-interactions.
- Design responsive & mobile-first.
- Suivi des tendances Webflow / Dribbble / Behance.

### e) Outils de développement
- Extensions VSCode pertinentes (Prettier, ESLint).
- Automatisation via GitHub Actions (tests, déploiement).
- Suivi des nouveautés GitHub.
